Exercise Tracker Web Application: 
A full-stack exercise tracking application built with React and REST APIs.

Features:
- Create exercises
- Edit exercises
- Delete exercises
- View exercise history
- Database-backed storage
  
Technologies:
- React
- JavaScript
- REST API
- Node.js
- Express
- MongoDB
  
Skills Demonstrated:
- CRUD Operations
- Frontend Development
- API Integration
- State Management
- Client-Server Architecture
  
Course: CS290 - Web Development
